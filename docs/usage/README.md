## 当前能力怎样理解

| 结果家族 | 当前使用方式 | 可回答的问题 |
| --- | --- | --- |
| 核心态势及留存异常 | 已有页面和只读接口；先确认所选日期及实际交付时段 | 留存了哪些异常、筛选后多少条、六类事件在已覆盖时段开始多少次、哪些前缀开始出现中断记录 |
| 单 RIB 规模与两次路径对照 | Core 已有相应查询结果；共享快照另需完成配置与登记 | 某快照可见多少唯一前缀、明确起源 ASN；两时点路径有何差异 |
| 独立 RIB 总体资源统计 | 已有 `/api/v1/resources`，读取实际交付的统计点 | 某时点有多少 IPv4 CIDR、IPv6 /48 覆盖块及其他固定总体资源量；不由单点推定连续状态 |
| 国家与 ASN 特征、档案 | 时序、聚合、国家两窗比较及档案查询 | 某窗口宣告撤回活动多少、末态覆盖资源量多少、指定两窗如何变化、候选范围内如何排名 |
| 国家中断详情与同期统计 | 按事件引用读取基础记录，再以相同数据版本查询国家特征与中断时序 | 事件截至何时仍未结束、峰值在何时及包含哪些 AS、同期活动和资源怎样变化 |
| 按发布绑定的国家事件观测 | 解析具体事件后按返回能力查询 | 固定事件窗口内的观测曲线、窗口 ASN 分类、路径关联及趋势；适用范围与普通国家同期统计分别解释 |
| 新国家计算、Resource 其他结果、资格化趋势与原始观察 | 已有相应计算或只读组件；不能据此认定已有统一 Web 查询入口 | 对已经产生且允许读取的结果，按各自指标定义解释；正式接入范围以已开放接口为准 |

这里的“已有接口”表示实现存在，不保证任意日期或对象都有数据。可用日期、事件、结果状态由实际查询确认；文档不固定一份“永远有效”的日期清单。

## 三个常见问题

**页面里的前缀数都是同一种数量吗？** 不是。唯一 CIDR 前缀数、IPv4 /24 覆盖块数和 IPv6 /48 覆盖块数分别定义，见[资源指标](metrics/resources.md)。

**国家中断是否表示全国用户断网？** 它描述相应观测范围内的路由异常。真实用户影响、转发连通性、原因和责任需要额外证据，不能由这些数值直接推出。

**能否直接自然语言问数？** 可以在[问数页面](http://10.99.8.16:28684/)选择已登记数据批次，询问事件、活动、资源和变化，并继续追问。应用结合本目录的业务说明与所选批次的只读 API 取数；数据范围和数值以实际响应为准。

## 文档如何分工

本目录负责业务含义与使用方法。接口精确结构以 [OpenAPI](../../contracts/openapi.json) 为合同依据，查询范围、兼容与退役状态在 [API 导航](api/read-api.md)中明确列出。领域身份术语见 [CONTEXT](../../CONTEXT.md)，架构、数据验收和运行状态继续由[项目文档导航](../../README.md#文档导航与权威位置)中的相应文档维护。

来源、版本、算法实现与参考映射由内部记录维护；用户通常只需要对象、时间、单位、结果和影响结论的限制。维护者可读[文档维护说明](../maintenance/系统使用文档维护.md)。
