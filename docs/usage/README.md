## 当前能力怎样理解

| 结果家族 | 当前使用方式 | 可回答的问题 |
| --- | --- | --- |
| 核心态势及留存异常 | 已有页面和只读接口；先确认所选日期可用 | 某日留存了哪些异常、筛选后多少条、哪些前缀开始出现中断记录 |
| 单 RIB 规模与两次路径对照 | Core 已有相应查询结果；共享快照另需完成配置与登记 | 某快照可见多少唯一前缀、明确起源 ASN；两时点路径有何差异 |
| 国家与 ASN 特征、档案 | 已有时序、聚合和查询接口 | 某窗口宣告撤回活动多少、末态覆盖资源量多少、候选范围内如何排名 |
| 已发布国家事件观测 | 先解析具体事件，再按返回能力查询 | 该事件窗口的观测曲线、窗口 ASN 分类、路径关联及已提供的趋势 |
| 新国家计算、独立 Resource、资格化趋势与原始观察 | 已有相应计算或只读组件；不能据此认定已有统一 Web 查询入口 | 对已经产生且允许读取的结果，按各自指标定义解释；正式接入范围以已开放接口为准 |

这里的“已有接口”表示实现存在，不保证任意日期或对象都有数据。可用日期、事件、结果状态由实际查询确认；文档不固定一份“永远有效”的日期清单。

## 三个常见问题

**页面里的前缀数都是同一种数量吗？** 不是。唯一 CIDR 前缀数、IPv4 /24 覆盖块数和 IPv6 /48 覆盖块数分别定义，见[资源指标](metrics/resources.md)。

**国家中断是否表示全国用户断网？** 它描述相应观测范围内的路由异常。真实用户影响、转发连通性、原因和责任需要额外证据，不能由这些数值直接推出。

**能否直接自然语言问数？** 本文为问数准备共同的业务说明。主线尚未因此新增通用 Agent 或 docs tool；独立历史问答能力的范围由原项目文档维护。

## 文档如何分工

本目录负责业务含义与使用方法。接口精确结构以 [OpenAPI](../../contracts/openapi.json) 为合同依据，已发现的实现差异在 [API 导航](api/read-api.md)中明确列出。领域身份术语见 [CONTEXT](../../CONTEXT.md)，架构、数据验收和运行状态继续由[项目文档导航](../../README.md#文档导航与权威位置)中的相应文档维护。

来源、版本、算法实现与参考映射由内部记录维护；用户通常只需要对象、时间、单位、结果和影响结论的限制。维护者可读[文档核对与未决事项](../maintenance/系统使用文档维护.md)。
