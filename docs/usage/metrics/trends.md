# 趋势分析

趋势描述已知样本中的下降、反弹、阶段和同期差异。反弹不等于生命周期恢复，同时变化不证明原因，采样数量也不直接等于持续时长。

适用范围：已有国家趋势产品及新方向趋势计算。下面的精确方向公式针对新计算；历史产品有独立的总体、规则和精度，使用其结果定义，不自动用新公式重写旧结果。新组件存在不表示所有事件已经有可查趋势。

## 基本符号与极值

对同一适用指标，设采样值为 x(t)，固定分母为 D，窗口首值为 x₀、末值为 x₁、最小值为 xₘ。原始数量沿用被分析指标的单位。

| 指标或结果 | 含义与单位 | 条件 |
| --- | --- | --- |
| 首值、末值、最小值、最大值及时间 | 相应样本值与其位置 | 新计算并列极值取首次；历史入口按自身规则 |
| 最大相邻下降／上升 | 相邻样本差 `x(t)-x(t-1)` | 是样本间变化，不是区间全部变化次数 |
| 可见比例 | `x(t)/D`，无量纲；展示百分数时乘 100 | D 必须已知、适用且大于零 |
| 相邻变化百分点 | `100 × [x(t)/D-x(t-1)/D]` | 单位百分点，不是相对变化百分比 |
| 归一化振幅 | `100 × [max(x/D)-min(x/D)]` | 单位百分点 |
| 累计波动 | 相邻变化百分点绝对值之和 | 单位百分点累计，不是网络流量 |

缺少样本时，可以描述已知采样极值，不能自动称为完整窗口极值。即使采样点齐全，也不证明采样之间没有更大的连续时间极值。

## 下降与反弹

| 字段 | 定义 | 单位 |
| --- | --- | --- |
| `start_to_extreme_change` | `xₘ-x₀`，首值到谷值的带符号变化 | 原指标单位 |
| `loss_magnitude` | `x₀-xₘ`，相对窗口起点的下降量 | 原指标单位 |
| `extreme_to_end_rebound` | `x₁-xₘ`，谷值到末值的反弹量 | 原指标单位 |
| `end_residual_from_start` | `x₀-x₁`，末值相对起点仍低的量，可为负 | 原指标单位 |
| `window_rebound_ratio` | `(x₁-xₘ)/(x₀-xₘ)` | 无量纲比例；仅下降量大于零时可计算 |
| 固定集合可见缺口累计 | `Σmax(D-x(t),0)` | 当前方向计算为方向×采样 |
| 窗口起点可见缺口累计 | `Σmax(x₀-x(t),0)` | 当前方向计算为方向×采样 |
| 阈值以下样本数 | 可见比例低于相应阈值的样本数 | 个采样点 |

累计缺口尚未乘以时间长度，不能标成方向·秒。样本数乘采样间隔也不自动成为已证明的连续中断时长，尤其需要检查缺口、边界和状态连续性。

## 方向、阶段与窗口形态

方向步数统计达到该规则方向条件的相邻变化。交替次数统计这些方向步之间的转换，交替比例以方向步数减一为分母；分母不足时不能给出有效比例。

突降位置、突降数量、稳定／下降／上升／低位等原子状态及合并阶段，都是相应计算规则的输出。窗口形态包括小分母、平台、振荡、多波、单波反弹、混合或未匹配等。使用返回分类及解释，不把主观观察替代已定义的规则，也不把形态标签当作根因。

## ASN、双栈、活动与同期参照

| 结果 | 含义与单位 | 解释条件 |
| --- | --- | --- |
| ASN 状态分布／转移矩阵 | 固定 ASN 总体的状态数量、相邻采样分类变化数 | unknown 单独保留，不当作正常 |
| ASN 最长连续同类样本数 | 同一分类连续出现的最大样本长度 | 不直接证明连续时间网络状态 |
| ASN 首末状态差异 | 窗口首末分类是否不同 | 不能由此称为整个窗口持续迁移 |
| 双栈可见比例差 | IPv4 可见比例减 IPv6 可见比例 | 单位百分点；不直接相减两族地址数量 |
| 双栈最大差异与极值偏移 | 最大绝对比例差的位置、两族极值位置差 | 先确认共同窗口和样本网格；偏移按返回时间／位置单位表达 |
| 活动峰值对齐 | 精确匹配 Feature 计数窗口与状态相邻采样窗口后比较峰值位置 | 仅时间接近不构成对齐；同时出现不证明因果 |
| 同期参照排名／百分位 | 在可比国家集合内的相对位置 | 指标、总体、网格和质量均须可比，不是全世界排名 |
| 共同下降数量／占比 | 同一间隔内满足下降条件的可比国家数及比例 | 保留候选总体和分母，不给出原因判断 |

## 如何取得

已有国家事件趋势通过[国家事件 API](../api/read-api.md#国家事件观测)按事件及同次读取绑定取得。趋势可能未配置或仅有部分支持的结果；不能用另一事件或其他窗口代替。新资格化趋势组件的实现范围见[趋势消费说明](../../architecture/国家趋势M3资格消费实施说明.md)。
