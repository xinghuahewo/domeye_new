# 资源数量、正常范围与拓扑

Feature 的 `ipv4_prefixes` 是 IPv4 /24 覆盖块数，`ipv6_prefixes` 是 IPv6 /48 覆盖块数，不能直接解释为唯一 CIDR 前缀条数。资源是时点状态量，跨时间相加不表示累计资源。

## Feature 文件末资源

适用范围：普通 Feature 文件处理结束后的资源状态；国家、ASN 和采集范围分别按相应成员集合解释。

| 计算字段／接口别名 | 定义与单位 | 汇总方法 |
| --- | --- | --- |
| `v4Prefix_num`／`ipv4_prefixes` | 不同 IPv4 /24 覆盖块数量，单位个 /24 块 | 按覆盖集合去重；跨对象取并集 |
| `v6Prefix_num`／`ipv6_prefixes` | 不同 IPv6 /48 覆盖块数量，单位个 /48 块 | 按覆盖集合去重；不同于精确 /48 等价量 |
| `v4IP_num`／`ipv4_addresses` | IPv4 /24 覆盖块数×256，单位个地址 | 属于按覆盖折算的地址量，不总是精确地址并集 |

单位示例：一个 /25 覆盖一个 /24 块，Feature 折算为 256 个地址；该 /25 的精确地址数为 128。一个 IPv6 /64 在 Feature 中占一个 /48 覆盖块，而在[新国家精确地址计算](country-calculation.md)中仅为 1/65536 个 /48。示例说明单位，不是真实测量。

以上资源可取明确末值、采样极值或两时点差值。跨 ASN、国家直接相加会因成员重叠而重复。缺行不自动等于零，延用上一资源值需要连续状态依据；读取时使用资源适用性允许消费的主值。

国家详情的三张资源图使用这些 Feature 指标。`country-feature-series/v4` 中以 `data.resources[].at` 表达实际文件末态时点，选择范围为 `start < at <= end`；`source.label` 是来源文件标签。资源量差值应保留两端实际时点，不能把一个末态样本解释为整个窗口的恒定数量。

## 档案中的资源变化

| 字段 | 当前含义 | 如何使用 |
| --- | --- | --- |
| `ipv4_prefix_change`、`ipv6_prefix_change`、`ipv4_address_change` | 当前窗口末值减前一窗口末值，沿用原单位 | 保留正负和两个实际有效时点；两端需可比 |
| `resource_change` | 当前取两族前缀覆盖变化绝对值的最大值 | 已标记 deprecated；混合 /24 和 /48 且丢失方向，仅作旧排序辅助；无可用变化时为 null |
| `resource_change_rate` | 两族可计算变化百分比绝对值的最大值 | 已标记 deprecated；不是双栈总体下降率；回答下降时应看单族带符号变化 |

如果要回答“哪一族下降最多”，分别比较 IPv4 或 IPv6 的同一指标。当前综合字段不替代这个比较。

## 独立 Resource 的资源量

适用范围：每次独立消费的一份完整 RIB。总体桶是该观测范围的总体；首路径 ASN 桶、按 peer ASN 分组的行不是任意起源 ASN 的资源档案。`/api/v1/resources` 已提供明确交付的 global 独立时点统计，具体可查时点由结果决定；完整组件的其他结果仍按各自接入状态判断。

| 字段 | 定义与单位 | 限制 |
| --- | --- | --- |
| `ipv4_prefix_count` | 去重 IPv4 CIDR 数，单位条 | 与 Feature /24 块数不同 |
| `ipv6_cidr_count` | 从持久成员集合可得的去重 IPv6 CIDR 数，单位条 | 需要相应成员结果；不能用兼容 /48 字段替代 |
| `ipv6_prefix_count` | 兼容字段，实际为 /48 覆盖块数 | 字段名不足以判断单位 |
| `ipv6_48_count` | 当前与上一项同值同单位 | 两者不是可相加的两个量 |
| `ipv4_address_count` | /24 覆盖块数×256，单位个地址 | 不是所有情况下的精确地址并集 |
| `vp_count` | 相应桶中不同首路径 ASN 的数量 | 不是完整 Peer 数或会话数 |
| `private_as_count`、`public_as_count` | 按兼容尾部 ASN 分类得到的去重数量 | 不是共享快照明确起源 ASN 数的别名 |
| `path_count` | 去重的渲染路径文本数，单位条 | 不等于原始路径属性字典条目数 |

按 peer ASN 的持久结果仅保留支持的前缀指标。某些结构默认值在保存时会变为 null；不能把未支持的 `path_count`、`vp_count` 等字段解释为已测得零。

当前 Web 固定提供表中的八个兼容数值字段，不包含 `ipv6_cidr_count`、正常范围、离群判断、国家拓扑或 peer 明细。`ipv6_prefix_count` 是 `ipv6_48_count` 的旧同值别名，已在合同标记 deprecated。每项返回主值、单位和适用状态：主值为 null 时保持未知／不适用；适用且确实统计为零时才能显示 0。

这些结果是一份份独立 RIB 的时点值。有一个 08:00 的点，可以回答“08:00 这份 RIB 中有多少资源”，不能据此回答“08:00—11:35 一直有多少”，也不能延长成整段平线。Core 的明确起源 AS 数另有定义，不能由这里的 `public_as_count` 代填。

## 正常范围与离群

| 字段 | 含义与单位 |
| --- | --- |
| `list_len` | 参考范围采用的历史样本数，单位个 |
| `mean` | 样本均值，沿用被评估资源指标的单位 |
| `population_std` | 样本总体标准差，沿用同一单位 |
| `upper_bound`、`lower_bound` | 当前计算给出的参考上界、下界，沿用同一单位 |
| `is_outlier` | 纳入判断的资源字段是否有任一项超出对应范围，布尔值 |

参考范围依赖适用的历史样本。冷启动或样本不足时，能产生上下界不代表已建立成熟正常范围；当前下界也没有统一的非负保证。算法实现与参考绑定由内部维护，离群结果只描述该采集视图的资源偏离，不直接等同故障或攻击。

## 拓扑

`node_count`、`edge_count` 分别为指定国家标签下计算拓扑的节点数和去重边数。边来自可解释路径中的相邻合格 ASN 关联，不代表物理链路或因果。关闭计算、无边、结果过大和缺少参考属性分别处理，不能统一补零。

AS 名称、组织、国家和排名属于实体属性，不是这份 RIB 计算出来的真实影响或网络重要性。独立结果的工程读取合同见[Resource 消费说明](../../architecture/Resource-M3公开消费合同.md)。
