# 单 RIB 规模与两次路径对照

单 RIB 规模是快照时点的去重数量；两次路径对照只描述两个明确时点之间的观察差异。它们分别不能解释为整日累计资源或区间内变化次数。

## 单快照指标

适用范围：一份明确 RIB、所选 IPv4／IPv6／双栈范围；ASN 查询再限定一个明确起源 ASN。Core 规模和共享快照的可用范围各自确认。

| 字段 | 业务含义与单位 | 去重与使用条件 |
| --- | --- | --- |
| `visible_prefixes` | 可见唯一 CIDR 前缀数，单位条 | 同一前缀被多个 Peer 看见只计一次 |
| `visible_origin_ases` | 可明确归属的起源 ASN 数，单位个 | 双栈合计也按 ASN 去重，不直接相加两族数量 |
| `attributed_prefixes` | 至少有一个明确起源的唯一前缀数 | 同一前缀有多个明确起源仍只计一条 |
| `unattributed_prefixes` | 完全没有明确起源的唯一前缀数 | 与上一项相加等于 `visible_prefixes` |
| `rib_entries` | 原始 RIB 观察条目数，单位条 | 相同内容的不同原始条目仍保留；不是唯一前缀数 |
| `unattributed_entries` | 无法明确归属起源的观察条目数 | 即使同前缀另有可归属观察，该条目仍保留 |
| ASN `prefix_count` | 与该 ASN 明确起源关联的唯一前缀数 | 多起源前缀可同时归属多个 ASN；各 ASN 数量之和不等于总体唯一数 |

没有明确起源的路径不强行选择一个 ASN。前缀、条目及归属的不同分母应保持清楚。响应内样本列表用于展示或核对，列表长度不替代完整数量。

这些值可按明确时点比较，也可对实际成员集合跨对象取并集。多天快照数量求和不能称为总资源规模。

## 两次路径对照

比较对象由两份 RIB 中的原始 Peer 属性组、地址族、后续地址族和前缀共同确定。可比较路径遵循该结果的解释规则，保留路径重复经过同一 ASN 等内容。

| 字段 | 含义与单位 |
| --- | --- |
| `same` | 两时点路径相同的可比较对象对数 |
| `different` | 两时点路径不同的可比较对象对数 |
| `left_only` | 仅左侧观察到的对象数 |
| `right_only` | 仅右侧观察到的对象数 |
| `not_comparable` | 因路径解释或配对等条件无法比较的对象数 |
| `comparable_pairs` | `same + different`，单位对 |
| `different_fraction` | `different / comparable_pairs`，无量纲比例；分母为零时不可计算 |

`different` 不等于期间路径变化次数。`interval_change_count` 当前没有可用的区间次数含义；两个端点相同也不证明期间没有变化。单侧缺项只表示该侧缺少对应观察，不能单独证明网络消失。

## 如何取得

Core 的规模、起源和路径对照分别读取响应中的对应可用状态。共享快照先发现可用快照，再以同一 `version` 查询总体和 ASN；版本绑定由调用程序保持，用户主要看到快照时点和业务数量。详见[选择数据与完成查询](../guides/query-data.md)。

完成文件交付模式中，Core 的 `metadata.rib_statistics` 消费离线生成的独立 RIB 统计，选择所选日、同采集器且在实际交付时段内最新的点。当前公开两个规模数 `visible_prefixes`、`visible_origin_ases`；事件与规模分别判断可用，缺资源不会抹去事件。它沿用规范前缀和明确起源的统计规则，保留时点，但不提供完整共享快照的 ASN 查询或原始观察分页。原 `/rib-snapshots` 的登记与同版读取合同继续独立有效。
