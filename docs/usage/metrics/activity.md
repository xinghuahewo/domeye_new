# 路由活动与档案聚合

`announce`、`withdraw` 表示通过相应 Feature 过滤的宣告和撤回**路由元素次数**，不是 BGP 消息条数，也不是去重前缀数。窗口比例先汇总次数，再计算分子与分母。

适用范围：普通 Feature 的文件窗口结果及使用这些结果的国家／ASN 档案。独立 IR 模式具有自己的过滤范围，与普通 Feature 分开解释。原始归档活动见[观察与状态](observations.md)。

## 基础计数

| 字段及别名 | 定义与单位 | 使用方法 |
| --- | --- | --- |
| `announ_num`／`announce` | 窗口内已接受宣告元素数，单位次 | 同义且不重叠、覆盖适用的窗口可求和 |
| `withdraw_num`／`withdraw` | 窗口内已接受撤回元素数，单位次 | 与宣告分开累加；不能将源缺失当作零撤回 |
| `update_total` | 窗口宣告总量 A 加撤回总量 W | 名称中的 update 不表示消息封装数 |

一条消息可能带多个前缀元素，重复宣告也可能增加活动计数。快照初始化不计为新宣告。

国家和 ASN 活动依赖相应起源归属：宣告使用新路径，撤回使用紧邻旧路径。采集范围还可能包含不能归属到 ASN 的已接受元素，因此各国家／ASN 活动相加不自动等于采集范围总量。

## 派生指标

设 A、W 为当前窗口活动总量，U=A+W，Uₚ 为前一等长窗口总量。

| 字段 | 含义、公式与单位 | 解释条件 |
| --- | --- | --- |
| `withdraw_rate` | `100 × W/U`，单位 % | 当前档案保留一位小数；U 为零或未知时无可计算比例 |
| `previous_update_total` | 前一等长窗口活动总量，单位次 | 前窗需要独立的覆盖依据；缺行不等于确认零活动 |
| `update_change_rate` | `100 × (U-Uₚ)/Uₚ`，单位 % | Uₚ=0 时不可计算；两窗定义、边界和覆盖须可比 |
| `peak_updates`、`peak_time` | 纳入样本中活动总量的最大值及时间 | 不等于连续时间中的瞬时峰值 |
| `volatility` | ASN 活动样本的总体标准差／均值×100，无量纲，按百分数表达 | 受样本数、稀疏和间隔影响；不能读为故障概率 |
| `sample_count`、`previous_sample_count` | 当前、前一等长窗口实际纳入的行数，单位行 | 不等于完整覆盖率，也不是消息总数；事件窗口模式未查前窗时前窗样本数为 0 |
| `latest_observation` | 对应对象或查询集合最近数据时间 | 集合最新时间不表示每个成员都同样新鲜 |

**档案空值规则：** 没有当前样本时，活动计数与峰值返回 null；存在明确零活动样本时计数为 0，但零分母的撤回比例为 null。没有前窗样本时，前窗总量与环比为 null。ASN 均值为零、少于两个样本或缺少标准差时，波动度为 null。排名排除对应排序指标不可计算的对象；样本存在仍不等于窗口完整。

国家与 ASN 档案在活动峰值并列时均取最早采样时点；此规则不自动适用于其他历史结果家族。

## 稀疏行与时间

活动按文件窗口清零。ASN 行可能按变化稀疏保存；仅在来源、处理完成和该对象的稀疏规则明确时，缺行才可能解释为活动零值。活动可以解释不代表同一行的资源状态也适用。

国家与 ASN 档案采用半开窗口，旧 Feature 时序接口仍有不同端点行为；拼接和比较前读[时间规则](../rules/time-and-aggregation.md)。不要平均采样点或各 ASN 的撤回百分比，使用完整 A、W 重算。

## 如何取得

国家／ASN 时序、单目标时序及档案聚合入口见[API 导航](../api/read-api.md)。普通档案窗口最多 24 小时；事件绑定的单 ASN 扩展窗口有额外身份和时间条件，见[事件查询](../guides/event-analysis.md)。
