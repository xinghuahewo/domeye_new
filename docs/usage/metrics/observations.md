# 原始观察与路由状态

消息、路由元素和状态变化分别计数；一条消息可含多个元素，一个元素也不一定改变路由状态。当前状态未知时，最后已知路径只能作为历史证据使用。

适用范围：原始观察归档、解析结果及路由状态计算。这里说明数据基础，不表示已经提供任意历史观察或状态的通用业务 API。

## 观察记录

| 数据或字段 | 定义与单位 | 汇总与限制 |
| --- | --- | --- |
| `messages` | 指定输入中的归档消息／记录数量，单位条 | 包含不同 MRT 类型，不能全部称为网络 UPDATE 消息 |
| `elements` | 归档路由元素数量，单位个 | 可按宣告、撤回、快照及地址族分组；与 Feature 过滤后的活动数不同 |
| 宣告／撤回／快照元素 | 对应动作的原始元素数 | 快照条目不计为新宣告；重试同一输入不能重复累计 |
| Peer 表条目 | 指定文件和 Peer 表位置的条目数 | 不是跨文件独立 Peer 数，也不是会话数 |
| 路径字典条目 | 存储的路径及属性字典记录数 | 不等于唯一 AS_SEQUENCE 文本数 |
| EOR、会话状态观察 | 记录中实际出现的控制信息 | 不是业务异常数量；首末观察或缺口不直接确定真实会话生命周期 |

同一份输入的多个处理尝试不代表更多原始数据。按输入集合汇总时先确认去重范围，不能把执行次数当作观测次数。

## 存在性与最后已知状态

路由对象在明确观测范围和时点区分**存在、明确不存在、未知**。解析缺口或断连可能使当前状态未知，不产生一条可以替代真实撤回的伪造记录。

最后已知路径、起源和时间描述历史证据。它可能早于查询时点，最后已知值也可能已经被撤回。当前状态失效时，不把旧路径继续称为当前可见路径。

状态变化次数需要明确比较前后状态及变化类型。全部元素数不等于变化次数。当前直接计算主链默认未保留完整的历史状态与变化明细，因此不能承诺对任意历史时刻直接返回状态或精确变化次数。
