# 对象与数据层次

Domeye 的一个数值必须同时说明对象、观测范围和时间。相同字段名不保证来自同一类结果，国家或 ASN 标签也不直接表示实际用户数量。

## 常用业务对象

| 对象 | 如何理解 | 使用时需要保留的区别 |
| --- | --- | --- |
| ASN／自治系统 | 以自治系统号定位的网络对象 | AS 名称和组织是属性；路径出现的 ASN 与明确起源 ASN 不同 |
| 国家 | 按相应国家属性选择的对象范围 | 不是全国所有网络的完整观测，也不证明物理所在地 |
| 前缀 | IPv4 或 IPv6 的 CIDR 网络 | 前缀条数、前缀覆盖地址量、原始路由条目数分别统计 |
| 路由快照／RIB | 某一观测时点的路由集合 | 某日的一份快照不代表该日所有时刻 |
| 路由活动 | 窗口内被接受的宣告、撤回元素 | 一条消息可包含多个元素；重复宣告也可能计入活动 |
| 异常事件 | 由类型、对象和事件身份定位的异常记录 | 事件、事件修订、底层现象和受影响对象分别计数 |
| 固定观测集合 | 某次分析固定使用的前缀、ASN、方向及分母 | 后续新成员不自动加入固定分母 |
| 观察方向 | 某一数据家族定义的观察单位 | 历史 peer ASN 去重与新计算的端点×前缀不能混用 |
| 路径关联 | 在有序 AS_PATH 中观察到的 ASN 关联 | 不要求直接相邻，不等于物理链路、商业依赖或原因 |

Collector、Peer、Session、RouteEvent、RouteState 的严格身份定义以 [CONTEXT](../../CONTEXT.md) 为准。单采集器限制了观察范围；缺少观察不自动说明网络不存在。

## 从初始数据到业务结果

| 数据层次 | 包含什么 | 适合回答什么 |
| --- | --- | --- |
| 原始输入 | MRT RIB、UPDATE 和参考资料 | 输入与来源核查；输入存在不等于业务结果完成 |
| 原始观察 | 消息、路由元素、Peer、路径、控制消息和解析结果 | 看到了什么原始记录；见[观察与状态](metrics/observations.md) |
| 路由状态 | 指定对象的存在性、当前和最后已知路径 | 解释计算依据；当前主链不提供任意历史状态的通用 HTTP 查询 |
| 基础计算结果 | Feature、独立 Resource、快照规模、路径对照 | 活动、资源规模和明确时点之间的差异 |
| 业务结果 | 六类异常、国家事件观测、ASN 分类、趋势和关联 | 异常检索、事件描述与变化过程 |
| 查询派生结果 | 总量、比例、变化、排行、窗口极值 | 回答具体问题；继承原指标的单位、范围和缺失限制 |
| 质量与执行信息 | 是否可读取、哪些点未知、是否处理完成 | 判断答案是否成立；执行成功本身不是网络业务结论 |

## 三种数量不要混用

**状态量**描述某时点拥有或可见多少，例如快照前缀数。跨时间可比较、取末值或采样极值，逐点求和不表示累计资源。

**活动量**描述某窗口发生多少元素，例如宣告和撤回次数。只有覆盖适用且窗口不重叠时才可累加。

**集合量**描述去重对象或地址并集。跨 ASN、国家、地址族或时间汇总时，需要按对象身份求并集；不能默认把各组数量直接相加。

## 有计算不等于当前可查询

读取具体数值前，需要依次确认：该结果的定义适用、结果已经产生、当前入口允许读取、查询所需范围可用。离线组件存在、页面存在、接口存在，都不能代替后两项。实际查询步骤见[选择数据与完成查询](guides/query-data.md)。
