# 时间、汇总与比较规则

先确认数值代表时点还是窗口，再决定如何求和、取极值或比较。未知不填零，比例从分子分母重算，唯一资源按成员并集汇总。

## 时间怎样解释

| 时间 | 含义 |
| --- | --- |
| 快照时间 | 该份 RIB 的实际观测时点，不是整天的代表性平均 |
| Feature 文件时间与窗口 | 活动是文件处理窗口计数；资源是文件处理结束后的状态；兼容字段 `t` 可来自文件标签，不能自动视为精确末态时刻 |
| 国家采样时间 | 曲线所用样本位置；新国家计算使用该时刻之前的状态，即 `state(t-)` |
| 事件开始、检测、结束 | 三种不同时间；结束未知不能补为查询结束时间 |
| 数据截止时间 | 当前结果读到哪里；不是事件结束或恢复时间 |
| 国家事件最后观测时刻 | `lifecycle.observed_at`，事件状态的实际观测截至时刻；与整批 `data_end_exclusive` 分别解释 |
| 结果更新时间 | 结果何时生成或更新；不是网络现象发生时间 |

当前业务时区为 Asia/Shanghai（UTC+8），业务日期和本地时间按此解释。现有 Feature／档案接口常接收 `YYYY-MM-DD HH:MM:SS`；国家观测返回的 UTC 时间在字段名中标明。显示或比较时统一时区，但保留实际时点。

## 当前接口的端点差异

| 入口或结果 | 当前端点含义 |
| --- | --- |
| Core 按日与小时窗口 | 查询边界和公开趋势桶的 `start`、`end_exclusive` 按项目业务时区（当前 `+08:00`）返回，按左闭右开解释；来源覆盖元数据可保留 UTC |
| 单国 Feature 时序 `country-feature-series/v4` | 活动区间完整位于查询窗口内；资源末态按 `start < at <= end` 选择，两组样本独立 |
| AS／前缀中断时序 `outage-series/v2` | 采样时刻满足 `start <= t < end`；有结束时间的事件仅在 `s_time <= t < e_time` 内计入 |
| 国家与 ASN 档案的 Feature 聚合、时序及关联事件 | `start <= t < end`；响应明确 `window_boundary=[start,end)` |
| 指定 ASN 的关联事件查询 | 按开始时间使用 `start <= s_time < end`；不是所有与窗口重叠的事件 |
| 原始兼容 Feature 时序与多处历史事件筛选 | 仍有右端点纳入行为，按相应入口读取规则处理 |
| 已发布国家事件曲线 | 使用事件绑定窗口与返回的时间数组，不能自行改成另一个窗口 |

时间字符串按业务时区解释。跨入口对账、拼接相邻窗口或计算环比前，按表中规则核对实际纳入的区间或时点；资源末态不能按活动计数的边界选择。档案中的并列活动峰值均取最早采样时点。

## 可以怎样汇总

| 数值类型 | 合法操作 | 关键条件 |
| --- | --- | --- |
| 宣告、撤回活动 | 在不重叠窗口求和 | 同一定义、输入无重复、所需窗口覆盖适用 |
| 时点资源量 | 取明确时点、末值、采样极值或两端差 | 不逐点求和为“累计资源”；末值保留实际有效时间 |
| 唯一前缀、ASN、地址 | 对成员集合取并集、交集或差集 | 不同分组可能重叠；只有已证明互斥时才能直接相加 |
| 比例／百分比 | 先合并同义分子和分母，再计算 | 不直接平均各对象百分比；分母为零或未知时不可计算 |
| 累计新增对象／地址 | 取窗口末累计值，或计算集合差 | 不重复相加多个采样的累计量 |
| 极值 | 在适用样本中取最大／最小，并返回时间 | 保留并列选择规则；已知样本极值不一定是完整窗口极值 |
| 平均值 | 区分采样平均与时间加权平均 | 不等间隔采样不能默认为等时长；时间加权需要连续性依据 |
| 排名 | 在明确且完整的候选范围排序 | Top N 或一页结果不能冒充全量候选；保留方向和并列规则 |

撤回比例的单位示例：窗口宣告为 80、撤回为 20 时，比例是 `20/(80+20)=20%`。这是说明公式的虚构数值，不是真实测量。分母为零表示没有可计算的比例，不是“确定为 0%”；档案的空值规则见[路由活动](../metrics/activity.md)。

### 时序的分桶统计

单国 Feature 与五个中断时序入口可选 `summary_seconds`（60–86400 整数秒），在同次读取中增加 `summary`，原始 `data` 不变。分桶从查询起点开始，最后一桶在查询末端截短；活动按完整区间落入桶内选择，资源末态按 `(桶起点,桶终点]` 选择实际 `at`，中断按 `[桶起点,桶终点)` 选择 `time_slot`，文件标签不参与选择。不重采样或插值。完整调用参数见 [API 导航](../api/read-api.md)。

每桶保留实际处理覆盖。点统计的 `first`、`last`、`known_sample_minimum`、`known_sample_maximum` 均同时包含 `value` 与 `at`：资源使用 `resources.at`，中断使用 `time_slot`。首末样本值未知时仍保留该时点与 null，不回退到另一条已知值。极值仅比较已知样本，并列取最早纳入样本；`known_sample_mean` 为已知样本算术平均，不是时间加权平均。`first_to_last` 保留两个点、差值及以首值为分母的百分比；缺少任一端点、只有一个样本或首末时点不递增时为 null，首值为零时百分比为 null。首个样本不自动成为正常或中断前基线，端点差也不是生命周期恢复。

活动统计的 `known_window_sum` 对应所列 `source_intervals` 中的已知文件计数。仅在文件窗口不重叠、恰好覆盖整个桶、交付覆盖完整且该指标无空值时，`total` 才表示该桶合计。跨桶边界的文件不纳入该桶活动合计，不能按比例切分计数；即使处理覆盖完整，非对齐桶也可能无法确认整桶合计，此时 `total` 返回 null。有重叠文件窗口时两种合计都为 null。资源量和并发中断数量不提供跨时点累加。

## 比较前要相同的条件

同一国家的两窗现有统计可使用[两窗比较入口](../api/read-api.md#同一国家两窗比较)，由程序检查完整活动区间、时长与空值后返回比较资格。该入口的末样本比较与整窗合计分别解释，国家总体统计不作为事件固定成员的恢复证明。

比较双方应具有相同指标定义、单位、对象总体、观察范围和可比时间粒度。固定集合、未知状态或纳入范围发生变化时，要说明差异；不能只凭 JSON 字段名一致就拼接序列。

连接数据前先明确关系：事件可有多个修订，一条前缀可有多个起源，一条路径可对应多次观察，一个事件可关联多个 ASN。汇总按所需对象身份去重，避免连接放大数量。

## 数据不足时如何表达

数据只支持已知样本时，回答“在已知采样点中……”。只有已知下界时，回答“至少……”。指定日期不可用时，说明缺少该日期数据；换日期或改用其他总体属于另一个问题。具体状态见[结果状态与完整性](result-states.md)。
