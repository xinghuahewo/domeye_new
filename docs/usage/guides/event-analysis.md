# 查询与解释事件

先取得具体事件引用，再读取该事件已有的事实、观测和分析能力。国家名称、时间相近或曲线相似，不能替代事件身份。

## 从列表进入详情

Core 页面以业务日期筛选留存异常，列表详情使用返回的 `ref` 和相同 `version` 调用 `/api/v1/core-overview/record`。完成文件来源也支持按时间段和国家筛选。历史事件列表另用 `/api/v1/events`，详情沿用该列表记录提供的类型、开始时间、对象、事件编号和来源。

这两条读取链有各自的数据范围。不要仅因某条 Core 记录包含相似对象，就假定旧库中存在同一份可读详情。用户界面入口为异常事件及事件证据页，具体 API 见[导航](../api/read-api.md)。

普通事件可读事实和限制后即可回答记录描述的问题。其 `semantic_guardrails`、`blocked_claims` 或相应限制由调用方保留；缺少可靠生命周期时，不补写结束、时长或恢复。

## 国家事件的查询顺序

国家中断详情显示检测时间、最早中断时间、事件状态、最后观测时刻、峰值时间、峰值受影响 AS 数、观测集合 AS 总数、峰值比例及可搜索、分页的峰值 AS 名单。各项以事件记录提供的内容为准，未知字段保留其状态。

`/api/v2/events/resolve?ref={事件引用}` 在完成文件模式返回 `country-outage-delivery/v1`，其 `event` 就是共用 Core 详情。事件按 `ref` 定位，页面导航中的 `date` 不替代事件身份。已经取得同版 Core 详情时无需重复解析；基础记录与同期统计直接读取已有事件和 Feature 数据。

调用顺序是：读取事件及其 `version`，从该来源的国家目录确认名称，再将同一版本、国家和所选时间传给[国家特征与中断时序接口](../api/read-api.md#单国路由活动与资源曲线)。国家曲线统计相应国家总体，不自动限定为上方事件的峰值成员。版本变化时重新读取事件及相关统计，保持同次查询一致。

历史发布模式仍按解析结果中的事件窗口、数据截止、发布身份和 `capabilities` 读取概况、曲线、ASN 名单及可用关联，按[历史观测说明](../metrics/country-published.md)解释。两种模式的响应与参数见 [API 导航](../api/read-api.md)，不互相补填缺少的身份或能力。

能力未配置、不可用或只允许审计时，保留对应限制。存在 `/trend` 或 `/path-downstreams` 路由，不代表每个事件都已有这些结果。

完成条件：事实与观测绑定的是同一事件和读取范围，所需能力实际可用，曲线和名单的指标定义已确认，分页范围足够支撑问题。

## 详情页的六张图

页面默认选择事件附近最多 24 小时的已交付窗口。可按北京时间填写开始、结束时间并点击“查询”，也可用“回到事件附近”恢复默认范围。时间选择须位于当前数据范围内；自动刷新保持手动选择的窗口。

| 图表 | 表示什么 | 时间与单位 |
| --- | --- | --- |
| BGP 路由活动 | 通过过滤的通告、撤回路由元素次数；一条 BGP 消息可包含多个元素 | 五分钟文件区间的计数，单位次 |
| IPv4 地址数量变化 | IPv4 /24 覆盖块数折算的地址量 | 文件末态，单位个地址 |
| IPv4 /24 覆盖块数变化 | 去重 IPv4 /24 覆盖块数 | 文件末态，单位个 /24 块 |
| IPv6 /48 覆盖块数变化 | 去重 IPv6 /48 覆盖块数 | 文件末态，单位个 /48 块 |
| AS 中断时序 | 采样时刻处于检测中断区间的去重 AS 数 | 每三分钟采样，单位个 AS |
| 前缀中断时序 | 采样时刻处于检测中断区间、符合粗路由筛选的去重前缀数 | 每三分钟采样，单位个前缀 |

活动只纳入完整落在所选窗口内的统计区间；资源按实际末态时点读取，可包含窗口终点；中断采样不含窗口终点。具体定义见[活动](../metrics/activity.md)、[资源](../metrics/resources.md)和[中断时序](../metrics/events.md#中断时序的覆盖合同)。

缺失样本和覆盖缺口显示为断线；已观测且确实没有中断对象时显示零。各类统计独立加载，读取失败显示对应状态，不把空图解释成没有路由活动或已经恢复。

## 什么时候最严重、影响哪些 ASN

“最严重”需要选定业务指标，例如中断前缀数或受影响 ASN 样本数，并按适用时间序列找极值。不同指标的峰值可能不在同一时点。

名单角色取决于实际响应。完成文件详情提供 `country_incident.asn_membership` 时，按[峰值快照定义](../metrics/events.md#开始结束持续和峰值)解释对应的 `asns`；历史窗口名单只表示整个窗口被纳入的 ASN。不能把任一种名单的长度当作另一条并发中断时序的峰值、当前值或分母。

路径关联说明共同观测到的有序路径关系。它可帮助描述关联对象，但不直接证明谁导致了事件。

## 读取同事件窗口的单 ASN 特征

现有 ASN 档案与精确关联事件查询支持事件窗口模式：指定单个数字 ASN，传入 `event_window=true`、`event_reference`，并将本地起止时间严格对应已解析的国家事件原窗口，最多 45 天。普通档案窗口最多 24 小时。

这些参数及返回范围已进入 OpenAPI，详见[ASN 事件窗口参数](../api/read-api.md#asn-事件窗口参数)。该模式不查询前窗，前窗活动与环比为 null，也不允许任意放宽窗口；共享时间也不表示 ASN Feature 与国家观测使用相同固定集合或指标定义。

## 什么时候恢复

先明确是在问某个观测指标何时回到指定水平，还是事件生命周期是否确认恢复。前者需要明确参照值或阈值、窗口、采样和缺失处理；后者按[生命周期字段](../metrics/events.md#开始结束持续和峰值)解释。

比较事件前后时，可用[国家两窗比较](../api/read-api.md#同一国家两窗比较)明确指定当前窗与参照窗。活动比较使用完整且等长窗口的合计；资源和并发中断比较使用两侧末个样本并保留实际时点。不满足比较条件时，差值或百分比保持未知。事前观测不自动等于正常基线，国家总体中的中断数量也不以归零作为默认恢复条件。数量减少只说明该指标的净变化；要判断原来哪些对象恢复，需要同一成员的前后状态证据。

趋势反弹、曲线回到窗口首值、`quality_state=complete` 或数据处理结束，都不能单独证明恢复。证据不足时分别说明观测变化与仍未知的生命周期。
