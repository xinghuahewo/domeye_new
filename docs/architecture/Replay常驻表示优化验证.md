## 诊断与表示改动

从原始容量核对继续，用同一流式 Message/Replay 测量，按对象 id 去重递归核算常驻对象。40 Peer／10万对象基线：字典42,016,536字节、字符串41,079,551字节、元组18,400,000字节、整数2,870,112字节；`current`首先归属79,477,671字节，`last_known`额外5,242,968字节。此为Python对象浅大小累计，不是RSS，不包含分配器空隙和扫描器本身。

只修改 `observations/state.py`：

1. 每个Replay持有8192项值LRU、128项前缀LRU，复用相等的不可变端点字段、ASN、路径key／原文、legacy VP／origin及相邻消息前缀。缓存淘汰只丢缓存引用，不删任何状态。类型敏感值缓存保留类型，不使用永久全局intern；长尾输入不会无界增长缓存。

未改唯一键、游标、身份哈希、RULE、有限事实、Session unknown、legacy折叠／历史origin残留／seen语义。current、last_known、legacy_paths、legacy_by_prefix、legacy_origins各自完整保留；没有磁盘状态后端或恢复协议。原始输入不变、不合并观察、不截断路径、不跳消息分支。
