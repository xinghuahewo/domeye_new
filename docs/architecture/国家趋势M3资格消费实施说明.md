## 当前已实现

- `m3_contract.Target` 从原行建立预期定位，包含逻辑运行、输入绑定、原表/全局序号、事件/revision/cohort、对象、AFI、指标、样本及结果窗口。资格不得通过另一行的同名维度替代。
- `m3_compute.Qualifications` 逐字段核对引用，分开原值、主值和有证明的下界。非完整资格不能提供精确主值；下界不进入比例或形态计算。缺资格返回具体 Unknown；断开的引用、同目标歧义、错人口、主值与原值冲突拒绝。
- `m3_inputs.EventSources` 保留原科学对象，为单事件建立有限索引。每个 MetricPoint 的固定分母资格独立消费，不能仅沿用事件方向分母；该对象没有数据库或验收能力，调用方仍须在构造前执行单事件资源计费。
- `m3_compute.event_series` 保留完整计算网格、原 MetricPoint 和事件起止，结果 D 的样本另列。Country owner 已明确：资格窗口为 D，带样本原行只在 `D_start < sample_us <= D_end` 产生资格；D 前原点不能由 D 内 complete 回填。事件结束不从最后样本构造。
- `m3_contexts` 保留局部 ASN/双族结果，缺资格对象不当作零人口参与整体排名。路径当前和历史分别输出原值、资格与 Unknown；没有 Session 连续性结论。
- `m3_coverage.coverage_rows` 要求独立12维原覆盖，仅事件枚举完整且零事件才输出 admitted_empty；其他维度 Unknown 不阻止已证明的空枚举，执行完成但枚举未知保留 unknown_empty。
- `m3_graph.evidence_rows` 延续旧科学图并追加资格引用；局部未知形成 Unknown，已观测零可以形成有限点值结论。
- `s3_schema` 使用独立 `country-trend-store/v2`、`country-trend-qualified/v1` 和 `country-trend-typed/v2`，保留旧44种行的覆盖范围，增加资格化点、路径、原资格/主值/覆盖及资格边。旧 `s2_schema` 常量、字段和读入口未改变。

### P1 四接口与锁

公开实现位于 `country_trend.s3_publication`：

```python
admit(runtime, owner_binding, *, guard)
verify_current(runtime, admission, *, guard)
hold_lock(runtime, admission, lock_target, *, guard, lock_connection=None)
open_reader(runtime, admission, request, *, guard)
```

`admit` 要求科学代码已固定提交，执行上述实际来源复算和湖审计，绑定实体、目录、全部依赖后登记 `country_trends.publication_admissions`。登记后的尾检查失败会撤销本次登记，不返回成功。`verify_current` 只核对实际登记、代码、目录元数据、实体戳及显式依赖当前性；不会重算科学正文。

Trend 自有锁均为 stage60：`trend.component` 的 key 为 component_id，`trend.admission` 的 key 为登记 UUID；若提供独立比较参考，增加 `trend.reference`，key 为该参考 sha256，锁实际 `country_trends.references` 行。每次 `hold_lock` 只持传入的一个显式目标，不隐藏调用上游 current/lock，也不在退出时验业务。M2/reference10、Canonical20、RFD30、Country40/50 和 Trend60 的全序由 Publication 统一安排，Trend 不把上游锁伪装成自己的锁。

读取请求字段固定为 `view, scope_typed, codec_version, batch_rows, batch_bytes`，codec 为 `country-trend-typed/v2`。view 为 `s3_schema.TABLES` 中54种明确 kind 之一，没有任意 SQL 或 all-table view。scope 无损编码为 `{'event': None或(incident_id, revision), 'key_typed': None或编码后的tuple, 'after_sequence': -1或原输出序号, 'stop_sequence': None或不含右端序号}`。读取单个有限表按原输出序号过滤；当前过滤仍需扫描该表，不能宣称索引裁剪。批字段为 `rows_typed, codec_version, rows, bytes`，每行封装 `{'kind': kind, 'row': 完整S3扁平行}`。

仅在完全耗尽、迭代器和文件关闭、尾 current 与资源检查通过之后形成 P0 ReadReceipt。早停、关闭失败或尾部失败没有成功回执；空 view 的回执不自行证明全局空事件，须读取 `result_availability/country_coverage`。

## 独立锁连接增量（待组合与实际验收）

本增量单独基于 `75dd800e2a2062eb9add49827779b441955ce124`，依赖全发布 owner 固定的 `2d744a863a19d890ba6a50bbc41936942ab2ee1a` 共享模块 `observations/publication_locks.py`，当前分支不复制或修改其他六类 owner。它不合入上面保留合法 a390 的科学/P1验收环境；最终组合顺序由父任务统一安排。
