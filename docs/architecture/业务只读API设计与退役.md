# 业务只读 API 设计与退役

本次以[系统使用文档](../usage/README.md)的数据定义为基准整理现有 API。查询围绕快照、事件、国家和 ASN 组织；原始观察、计算候选、已发布结果分别接入，不能因为都有数值就混成一种指标。

状态：本页描述 2026-09-21 的源码与合同改动。现有 37 个 GET 入口收敛为 31 个，其中 6 个保留为兼容入口并在 OpenAPI 标记 `deprecated`。P0 和旧 dashboard 的 6 个接口移除。源码同步、部署和实际数据可用性分别确认，本页不宣称线上服务已经切换。

## 从数据基础确定公开范围

| 数据基础 | 对外用途 | 当前决定 |
| --- | --- | --- |
| 原始 MRT 与完整 Observation | 核查具体观察、定位原始证据 | 复用已有有界观察读取；共享 RIB 有分页。不开任意路径或 SQL 查询，不把所有历史状态查询承诺给普通问数 |
| RouteState 与最后已知状态 | 解释计算依据 | 保留内部计算职责；当前默认主链没有任意时刻完整历史状态服务，不新增空接口 |
| 已登记共享 RIB | 总体及明确起源 ASN 资源规模 | 保留发现、同版总体、同版 ASN 和有界观察分页；未知日期不切换其他日期 |
| Core 留存异常与既有规模／路径结果 | 日期范围内的异常检索、概况与详情 | 保留同版读取；异常列表、规模和路径分别判断可用状态 |
| 现有 Feature 数据库结果 | 国家／ASN 的活动、末态资源、排名及档案 | 保留业务查询；修正时间边界、缺失和派生比例，不更改生产算法或重算历史数据 |
| 六类历史事件事实 | 按记录检索异常、读取事实与限制 | 保留；不由历史结束缺失推定仍在发生 |
| 已发布国家事件观测与趋势 | 某事件的曲线、ASN 窗口名单、路径关联及趋势 | 保留解析和同发布读取；按响应家族解释方向、地址和分类 |
| 新 Feature／Resource／Detection／Country／Trend 资格化结果 | 后续查询已完成且适用的计算结果 | 先接既有资格读取合同与实际登记，再扩展业务查询。组件实现或单次候选不能直接冒充全面可用 |
| 旧 P0 候选仓库与旧首页聚合 | 已退出当前产品入口 | 退役 HTTP 和专用服务；保留独立的历史制品、离线数据合同与共用质量能力 |

这是对目前能读到什么的划分。不能为了让问数看起来统一，就在一个入口内把共享快照失败替换成旧 Feature 资源，或把历史国家分类替换成新分类。

## API 按业务结果组织

路径的 `/api/v1`、`/api/v2` 是现有接口前缀，不是数据新旧或可信程度的判断依据。本次完善已有入口，不为了改名再复制一套相同查询。

| 业务能力 | 入口 | 用法与完成条件 |
| --- | --- | --- |
| 服务健康 | `/api/v1/healthz` | 只证明进程可响应，不表示业务数据完整 |
| 核心态势 | `/api/v1/core-overview`、`/record` | 先看日期与子结果状态；详情沿用列表 `ref`、`version` |
| 共享快照 | `/api/v1/rib-snapshots`、`/{version}`、`/{version}/asns/{asn}`、`/{version}/observations` | 从登记发现实际快照；总体、ASN、审计分页绑定同版 |
| 历史事件事实 | `/api/v1/events`、`/events/top`、事件详情、evidence-bundle、story | 分清全量窗口列表、近期列表、特定事件叙事；事实与生命周期限制一同读取 |
| 国家与 ASN 活动资源 | `/api/v1/features/top`、`/countries`、`/ases`及档案／ASN 关联事件入口 | 活动与资源单位分别解释；对象分页不等于完整时间覆盖，运营候选排名不等于全部 ASN |
| 国家事件分析 | `/api/v2/events/resolve`，以及 `/api/v2/country-outages/{incident_id}` 下的 overview、series、asns、path-downstreams、trend、audit | 先解析、检查能力，再保持 `publication_id` 读取；只有审计权限的结果不当作普通业务能力 |

每条完整路径与参数见[业务 API 导航](../usage/api/read-api.md)，精确字段以 [OpenAPI](../../contracts/openapi.json) 为准。导航负责“怎么查”，合同负责程序如何调用，指标页负责“这个数是什么意思”。

## 本次完善的查询语义

### 国家／ASN 档案采用半开窗口

`/features/countries/overview`、`/features/ases/overview` 及 `/features/ases/events` 统一使用 Asia/Shanghai 的 `[start_time,end_time)`。国家与 ASN 档案的 Feature、关联事件、时序和小图按相应窗口排除结束时刻，避免相邻窗口重复计入边界记录。两个档案响应增加 `window_boundary`。

开发数据时间守卫允许这些半开查询的结束时刻恰好等于配置的排他上界；不因此允许查询界外记录。原始兼容 Feature 时序和旧事件列表仍保留自己的端点规则，未宣称全站所有历史入口已统一。

活动峰值并列时，国家与 ASN 档案均选择最早采样时点。数量仍是已观测样本的聚合，不由半开窗口推出采样完整。

### 缺失、零与不可计算分别返回

| 情况 | 当前返回 |
| --- | --- |
| 当前没有 Feature 样本 | `announce`、`withdraw`、`update_total`、`peak_updates` 为 null；`sample_count=0` |
| 有明确零活动样本 | 相应活动计数为 0，保留样本数 |
| 宣告与撤回总量为零或未知 | `withdraw_rate=null`，不是 0% |
| 前窗无样本或事件窗口模式没有查询前窗 | `previous_update_total=null`、`update_change_rate=null`；增加 `previous_sample_count` |
| ASN 均值为零、少于两个样本或缺少标准差 | `volatility=null` |
| 资源两端不足 | 相应变化保持 null；综合旧排序值也不补零 |

排名排除其排序指标不可计算的对象。国家和 ASN 页的模型及显示同步保留 null，以“—”表达，没有把空值再次变成零。样本行数不是来源完整性证明；旧库缺口的完整覆盖资格仍需后续数据链提供。

`resource_change` 与 `resource_change_rate` 继续支持现有页面，但字段已标记 deprecated：它们混合两族或丢失方向。问数应选定 IPv4 或 IPv6 的带符号变化；不把它们解释成统一资源量或双栈总体下降率。

### 参数与错误形成正式合同

普通档案最多 24 小时；ASN 事件窗口模式最多 45 天，并要求单 ASN、合法事件引用以及与该国家事件完全相同的起止时间。`event_window`、`event_reference`、`event_window_selected_asn` 已进入 OpenAPI 和生成类型。

事件窗口布尔值只接受 URL 中的 `true`、`false`，不静默容忍拼写错误或重复参数；普通模式不接受非空事件引用。时间格式、必需参数和反向区间错误返回 HTTP 400；Feature 单目标读取失败保留结构化错误，不返回内部异常字符串。未配置或无法核对国家事件窗口时返回已有 503 状态。

## 退役与保留清单

### 已从源码移除

| 旧入口 | 处理 | 迁移含义 |
| --- | --- | --- |
| `/api/v1/p0/status` | 移除路由、专用服务、合同与启动变量透传；返回 404 | 当前数据是否可查，分别通过 Core、快照发现、事件解析及相应结果状态确认 |
| `/api/v1/p0/metrics/{metric_name}` | 同上 | 按业务问题使用相应家族；不能将旧五分钟包装当成新指标目录 |
| `/api/v1/p0/quality` | 同上 | 保留各数据家族的资格／质量信息与内部审计，不提供假定统一的新质量端点 |
| `/api/v1/dashboard/counts/total` | 移除路由、专用服务和合同；返回 404 | 若问 Core 留存结果，用 Core 的日期与统计范围；若问旧事件记录，用明确窗口的事件列表统计 |
| `/api/v1/dashboard/counts/type` | 同上 | 使用相应列表筛选，不能把旧近期数量静默换成某日数量 |
| `/api/v1/dashboard/overview` | 同上 | 当前首页已经使用 Core；新旧来源及生命周期含义不同，不作自动重定向 |

移除范围依据当前项目消费调用链：P0 与旧 dashboard 前端已经不存在，相关后端专用模块没有其他产品调用者。旧 `database/dashboard.py` 的共用事件类型等仍被国家／ASN 查询引用，保留该共用模块。原始数据、历史制品、`common/metrics`、`common/quality` 与离线 Schema 不删除。历史定义见[退役指标说明](../history/遗留P0与Dashboard.md)。

所有退役入口在开发时间限制开启时也保持 404，不被旧时间参数校验改写为 400。旧 P0 配置键接受后丢弃，不阻断其他业务启动，也不能恢复数据读取。线上运行目录若尚未切换，仍可能保留旧接口，需另行核对部署状态。

### 暂时保留并标记 deprecated

| 入口 | 保留原因 | 后续退役条件 |
| --- | --- | --- |
| 五个 `/api/v1/features/outages/*` | 国家与 ASN 页面仍调用部分旧并发曲线，未有可直接替换的完整时点结果 | 先建立同一对象、窗口、生命周期及缺失语义的替代结果，并迁移页面；不能用 Core 的每小时开始数冒充并发数 |
| `/api/v1/events/observations/{...}` | 旧引用的兼容入口 | 新调用使用 v2 事件解析及同发布读取；确认相关兼容消费者迁移后删除 |

这些入口不作为新增问数能力的首选。deprecated 表示仍可兼容读取，与已经移除并返回 404 分别处理。

## 后续结果接入应满足什么

新计算结果应复用已有[观察消费](观察只读消费接口.md)、[Resource](Resource-M3公开消费合同.md)、[国家](国家C4公开接口.md)及[趋势](国家趋势M3资格消费实施说明.md)合同。未来的业务查询应只读取已经登记、适用、同一绑定的结果；GET 不重放 RIB／UPDATE、不执行检测、不补建索引或发布结果。

接入前需确定：业务对象与筛选、时点或窗口、指标单位、分母和聚合、空值与下界、分页／排序总体、数据可用范围、查询预算及同版读取。接口提供数值和机器需要的状态／身份，普通回答只呈现业务含义及必要限制。

目前不新增一套假统一的“所有指标查询 API”，也不开放未经实际绑定的新 Resource、全历史 RouteState 或完整新国家结果。缺少发布登记、覆盖证明或业务读取实现时，明确作为接入缺口；不是再包装一次旧 P0 就能补齐。

## 验证范围

退役回归检查应覆盖 404、时间守卫、禁止读取数据以及启动不导入已删服务；合同检查覆盖运行路由、局部引用、事件窗口参数、nullable 类型和生成类型。

数值回归通过公开 HTTP 验证无样本、明确零、零分母、前窗缺失、有效环比与排序；在内存 SQL 样本中核对排除右端点、资源末值、前窗为空与并列峰值。前端检查 null 归一化、页面百分比显示、现有测试与构建。

这些检查使用 fixture、mock 和内存数据，不能替代真实发布覆盖或线上切换验收。最终执行结果随本次代码交付记录，未重新生产或更改历史业务数据。
