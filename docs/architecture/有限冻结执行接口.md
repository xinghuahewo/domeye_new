# 有限冻结执行接口

状态：已从 Resource 经独立复核的有限机制提取共享实现；不是动态插件、热加载或自动依赖发现平台。`backend/data_pipeline/common/frozen_execution.py` 仅依赖 Python 标准库。

每个模块负责自己的显式文件分组、依赖包版本列表、入口脚本和请求解码。入口在任何项目包导入之前，通过 `runpy.run_path` 读取本共享文件及本模块的纯标准库身份配置，构造 `identity_builder(root)`。

1. `code_identity(root, groups, packages, schema=...)` 枚举显式模式、原文件 SHA、分组、Python 与包版本；缺文件、符号链接、目录拒绝。调用方必须完整列出所有实际项目 helper、共享 Reader/decoder/reference、身份模块、入口与锁定依据。
2. `enter(root, entry, request, identity_builder, child=False, expected_digest=None)` 在父进程复制上述文件，核对复制前后身份，设置文件/目录只读；以当前解释器 `-I -B` 启动快照内入口，传递父进程固定摘要。父进程返回 False；子进程必须转交 `--frozen-child`、`--expected-digest`，通过孤立解释器、摘要、只读/无 pyc、未提前导入业务命名空间核验后才返回 True。
3. 返回 True 后，入口才能将快照 backend 加入路径并导入业务。`execution_identity(root, identity_builder)` 在业务开始和完成提交之前核验相同 PID/root/源码及包版本，并检查已加载的 `data_pipeline`、`utils` 模块实际 `.py` 来源均在清单内。输出包含 snapshot_digest、snapshot_root、PID 和实际 module_sources；业务回执绑定此身份。新增命名空间须通过 enter 的 namespaces 显式声明。
4. 直接 API 仅可显式使用 `fixture_only=True`，标记 `synthetic-fixture-api`；正式消费默认拒绝 synthetic，不能因为磁盘哈希存在就声称实际执行代码已冻结。

调用合同只支持本次创建的临时只读快照及固定请求，不提供长期快照选择、恢复、网络下载、依赖安装、凭据发现或任意模块调度。请求内容不复制进源码快照。快照在子进程退出后清理，回执保留文件摘要和绑定证据；这不是抵御同权限恶意进程的安全隔离设施。

人工测试使用真实新子进程：成功读取 fixture 业务值与实际来源；导入后源码修改拒绝；直接 API 正式身份拒绝；缺少显式依赖拒绝。来源参考：Resource 提交 `6ca6517d3dbf2f1e62ec2bb487b5adc5ff99e467` 及其独立 GO 报告 `0d0b3710872cf5de8f6d1e7ee0c6ad057f8c393c`。共享提取实现另行供消费者固定提交复用。
