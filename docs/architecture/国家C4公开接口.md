## M3逐维结果接口候选（已实现，待完整独立验收）

本节说明`m3_*.py`独立版本；下文旧21表C4、fixture验证器及历史成本继续作为历史记录，不替代M3准入。M3组件保留原21表及原逻辑行序，在完整原C2Completion之后追加`country_qualification`、`country_qualified_value`、`country_coverage`三个表。原科学数值、完整历史修订、嵌套原字段、来源全局序及Unknown均保留。

`m3_query.prepare_qualified_country_index`消费实际24表C3完整流，完成全部定位回读后才登记C4 PG验收。`inspect_qualified_country_result`核对原完整Proof、实际登记、实体及完整来源。二者均要求实际`M3Source`及其持有的上游锁；不是可外部注入的布尔资格函数。

`m3_publication`提供Country owner的`Runtime`、`inspect_binding`、`admit`、`verify_current`、`hold_lock`、`open_reader`。正式准入必须运行已提交验证器；从C3保留的原证据恢复M2、全部11参考、Canonical、Detection共14份实际Admission和35份完整公开读回执，逐一核对当前依赖。完整owner binding包含原`CountryReadBinding`与`CountryAdmissionProof`的规范编码。实际锁目标是阶段40的`country.component`，阶段50的`country.admission`及`country.read_model`；每次`hold_lock`只持一个实际目标。上游新规则产生新Admission时，旧C3不能自动视为current。

公开请求是五字段`view/scope_typed/codec_version/batch_rows/batch_bytes`，codec为`country-result-typed/v1`，正文沿用`component_schema.encode/decode`无损编码。scope字段为`window_us/dimension/incident_id/revision/table/after_sequence/stop_sequence`；窗口必须精确等于结果D，事件与修订必须成对提供。原行序号范围不重编号。

| view | 返回内容 |
| --- | --- |
| events | 原EventStatus、资格主值、D原lifecycle、完整原历史修订及相关资格 |
| country_qualification | 逐原目标的12维资格、原证据/Gap/恢复见证引用 |

所有新增资格的`window_us`是结果D。C3的`parameters.grid`保留完整计算窗，`parameters.result_window_us`单列D。带样本的资格遵守原C2左极限样本边界`D_start < sample_us <= D_end`；D之前的原MetricPoint保留在raw中，但没有据此生成D外资格。完整历史修订不按D裁掉，原起止和观察时间不改。不能以D内complete反填前史，不能把方向分母推广至其他统计人口。

首次`admit`装载完整保留来源、复核C4完整索引证明，并执行当前C3全体原行与资格审计；可信PG验收保存可复用descriptor。后续`verify_current`只核实际登记、完整绑定、固定PG目录元数据、代码规则、文件实体stat及各依赖current，不装载原正文、不作全文hash或科学推导、不取行锁。正式`open_reader`复用可信descriptor，只取所请求行；全局锁由调用方按阶段排序调用各owner的单目标`hold_lock`持有，current或页读取不暗中重新取得上游锁。

读取全批、关闭本次句柄、末尾current复验完成后才给`component-publication-read/v1`尾回执；外层发布锁生命周期仍由发布方负责。早停、异常、预算不足不产生尾回执。页面尾回执不冒充全C3审计，事件数0也不自行证明可用空结果。当前路径恢复须有原对象精确后态见证；历史完整性及Session连续性分别判断，不能由恢复当前值反推历史完整。

Runtime显式选择`fixture_only=True`或`execution_profile='real-candidate/v1'`。真实候选必须提供完整`expected_country_binding`、`ResultLimits`、`max_source_rows/max_source_bytes/lock_timeout_ms/min_free_bytes/max_temp_bytes/memory_bytes`；DSN、允许根、输出、隔离scratch、依赖与资源值在Runtime内固定。不同模式的依赖不得混用。查询DuckDB实际注入内存、临时目录与临时盘预算，原行/引用/字节/索引预算跨同Runtime读取累计；没有处理总截止时间。

## 实际运行入口与发布方接合

`query_index`提供prepare_country_index、inspect_country、read_country_event、iter_country_events、iter_country_aliases；`query`提供open_qualified_country与CountryQuery.query/iter_query。新增C3公开component_access.FixedComponentAccess承担布局/定位读取，原ComponentReader严格stream/page未改。query_contract保持父固定f0db76c，未各自增改共享字段。

prepare完整消费一次C3.stream，暂存原typed值用于独立对照，再读取两列定位、逐原行及全部业务定位页回读，才封存AdmissionProof。SQLite持久保留行定位、引用posting、有限view键、ASN/overview小摘要与静态投影；scratch正文与参考原行临时库删除，矩阵/路径正文仍在C3。inspect复验索引SHA/结构/计数、证明、实体与来源资格，不运行C3.stream。其索引扫描仍有离线成本，不称常量校验。

静态参考构造示意（c1、component_dsn、source_verifier均为调用方明确注入的本任务角色）：

```python
from data_pipeline.country_enhancement.component import database_identity
from data_pipeline.country_enhancement.query_contract import ReferenceBinding, CountryRuntime, digest
source = c1.identity['reference_sources']['as_info']
reference = ReferenceBinding(
    **database_identity(c1.reader.dsn), run_id=c1.reader.run_id,
    snapshot=c1.reader.snapshot, manifest_sha256=digest(c1.reader.manifest),
    source_id=source['source_id'], content_sha256=source['source_id'],
    expected_rows=source['rows'])
runtime = CountryRuntime(component_dsn, c1=c1, verify_qualification=source_verifier)
```

manifest_sha256为完整Observation manifest的规范JSON摘要。Descriptor.entities包含C3 21个Parquet、C3 manifest/ready、C4 index/manifest/ready；C4 manifest承载AdmissionProof及验收摘要。Observation/Detection湖文件、原输入/参考实体由发布owner离线补入统一manifest并复验，本模块不冒称已覆盖其文件锁。Source verifier离线接受descriptor，查询显式接受selection；没有真实验证器则inspect拒绝。

发布方通过read_country_event(descriptor, incident_id=..., revision=...)取已选EventStatus；revision=None只表示返回该组件已固定选中项，不发现新head。iter_country_events流式枚举E条EventStatus，结束给QueryReadReceipt并核C3事件总数；发布方据此对完整集合做profile原因白名单门禁。

两字段同时注入CountryRuntime，源信息进入封存索引身份。每条映射保留额外原字段并核目标事件/revision/cohort，result由descriptor明确。iter_country_aliases只接受source/table/ref_kind/id精确filters_json；没有来源抛C4_alias_not_available；明确完整来源但零命中仍给rows=0尾回执。按source/table/ref_kind/id/原ordinal排序，保留重复及多目标；query先有界扫描全部alias索引候选判断歧义，再返回当前页，不把第一页无冲突当唯一。分页重复该候选扫描成本受max_index_steps/max_rows约束，不读取全湖正文。

普通query用keyset和冻结total，带筛选时执行有界索引计数；按整页涉及的row-group合并读取。footer序列化字节与Arrow缓存共同限额，实际Python/Arrow额外内存由RSS上限约束。QueryReadReceipt只在从第一页完整迭代、count=total和尾资格复验后产生；早停没有回执。audit的kind=component_scope显式读取组件级原行，其余kind为21表白名单；事件audit只关联实际引用。缺基线overview的路径/ASN/采样汇总为None，合法无样本与已知零行另列，不补零。
