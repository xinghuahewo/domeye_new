# 国家增强 S1/S2 纯计算合同

2026-09-13。**状态：父协调任务已接受的新规则已实现为纯计算与人工fixture；尚待独立review。** 不代表历史general/v1等价、真实D可用、PG/Parquet持久化、HTTP或前端验收。接缝依据与历史区别见[国家增强计算接缝核对](国家增强计算接缝核对.md)。新规则版本为 `country-enhancement/bounded-v2`。

## 使用接口与身份

代码位于 `backend/data_pipeline/analysis/country_events/`，不导入Replay、MRT解析器、旧模块或数据库。`models.py`定义不可变typed输入，`cohort.py`提供S1，`compute.py`提供S2。所有时间使用整数epoch加可选microsecond；None表示原精度只到秒，不能解释为记录恰好发生在该秒零微秒。

1. 调用 `select_baseline(incident, candidates)` 从同一Binding的基线描述中选择已知事件边界之前最后可用状态。原onset存在则绝不回退pre_detection；onset未知才使用detected_at。原onset_cursor已证实时按游标选择前态，否则基线整个原精度区间必须严格早于边界。无基线返回None。候选描述必须是上游已保存计算状态的真实可用位置，不能只提供一份较早RIB而隐瞒其后已有前态。
2. 调用 `freeze_cohorts(incidents, baseline, routes, references)`。routes来自该基线cursor的状态，按prefix字典序连续分组，不能含未来游标、重复对象键或混Collector。references每ASN一个显式解释结果；重复/冲突必须在Reference里标明，不允许last-write-wins。一次基线扫描服务所有指定国家；不按国家再加载全部历史。
3. 调用 `compute_country_enhancement(cohorts, binding, grid, changes, paths)`，迭代返回 `Batch(binding, rule_version, rows)`。本最小切片一次调用只接受同一基线的一组cohort；不同基线必须显式分组，不能混成一个current。后续若要单流支持不同基线激活点，需要单独实现游标激活；当前没有该能力，不能称已覆盖任意多事件基线。

Binding必须包含run_id、snapshot_id、collector、ordered_sources、reference_version、decoder_version、state_rule_version和complete状态。本纯接口只校验这些声明，不连接PG验证真实完成回执；生产adapter以后必须先通过公共Reader门禁。每个输出Batch绑定原Binding，cohort行绑定cohort_id，完成不自动生成publication_id。

## 已保存行到typed输入的责任

| 输入 | 本轮typed字段 | 上游adapter必须保证 |
| --- | --- | --- |
| baseline state | Route.object_id/endpoint/prefix/path_id/presence/path_ref/origin/observation_ref/observed_at/cursor/mapping_ref/peer_ref/mapping_state/fact_presence/local_message | object_id绑定既有object_key；endpoint保留collector、remote/local、interface、AFI/SAFI。原Peer和映射引用必填，不宣称稳定Session；精度从原messages关联取得 |
| changes | Change.cursor/at/source_id/reference/after | after是保存的calculation_after，不是原始A/W重新计算；同对象ID的endpoint/prefix/path_id不可改变。cursor/source必须匹配有序清单 |
| invalidations | Change.invalidated_objects，after=None | 同一STATE对应的多行失效按同一cursor组成对象ID元组，保留STATE引用。只失效列出的已知对象，不制造withdraw；不从同IP/ASN扩展作用范围 |
| source quality gap | Change.gap=True、invalidated_objects可选 | 有据对象范围就列对象；无范围则此调用中总体进入未知，持续保留缺口限制。本版不以新A自动宣布全局gap闭合 |
| path dictionary | Path.path_ref/segments/raw_attributes/as4_segments/relationship_ref | 原segments、重复、集合、AS4和原属性不可变，引用一次；不以内容去重观察。没有路径字典引用就失败，不能造空路径 |
| country reference | Reference.asn/country/source_ref/state/historical_state | 归属映射与历史有效性分开；unknown/conflict不强归国家；所有源行原件由上游保留 |
| incident | 原生incident/revision/country、onset/cursor、detected_at、end、carry_in_state、legacy_ref/source_episode_ref可空 | 旧秒级起止不补微秒；旧v2身份是外部引用，新country ASN角色为not_applicable，不受旧attacked_as缺参整体降级 |

S1保留固定prefix的全部起源关系和unknown观察，MOAS不压成单ASN；未知归属前缀留在excluded_unknown。LOCAL不能选择cohort或推进收到的路由，原行仍保留。S2返回ObservationFact以保留变化原时点事实和LOCAL/unknown内容，事实只作用原观察，不证明采样时刻持续可见。

## 数值、状态与时间

- 新方向为既有calculation endpoint加prefix；path_id仅是方向内路由对象。基线present且bound的方向计入固定分母；unmapped/ambiguous或基线unknown导致受影响完整分母不可知，原条目不丢。legacy Prefix×VP没有在本模块复算或改名。
- 同一固定方向有任一路由present则计算存在；全部已知对象absent才计算absent，其余unknown。Prefix全present正常、全absent完全中断、确定present与absent并存部分中断，其余unknown。ASN分别输出AFI=1、2和AFI=0（两族合并）状态，完全可分类才输出normal/affected/route_interrupted。总体ASN数以AFI=0计，不把双栈重复加两次。
- WindowClass与AsnPoint分开：窗口曾route_interrupted优先，随后曾affected，再曾normal，否则unknown；保留observed_slots/unknown_slots/included_reason。Peak每指标独立，平峰取最早样本及次数，保留已知/未知槽数；不能据此拼出共同峰值时点。
- MetricPoint.value为B精确计算值；无法完整计算则None。known_lower_bound单独表示已知子集下界，denominator/ratio分别表达，空分母ratio=None。B的零值状态为calculated_zero，**不称A的observed_zero**。fact_value=None/fact_state=unknown保留连续性不足，原时点事实在ObservationFact中；B可以保留数值与三项明确假设。
- IPv4地址覆盖做去重并集，IPv6覆盖并集除2^80，使用Python Fraction精确表达（例如/49为1/2）。后续typed存储须存分子/分母或精确DECIMAL，不能经float/旧integer截断。MOAS逐ASN关系不能相加为国家资源，旧Resource /24另版。
- 新方向输出NewDirectionPoint，不扩固定分母，不声称新增独立Peer；新前缀输出NewPrefixPoint，当前与累计轨道分开。未知起源的新观察只保ObservationFact，不归到国家或ASN 0；新前缀不抵消固定集合中断。
- Grid显式input_start_us/input_end_us/samples_us。采样为state(t-)，只消费原时间严格早于t的变化；正好右端的消息不会进入右端状态。原秒精度横跨微秒采样边界时直接失败，不猜顺序。源游标或原时间回退时运行失败并且没有Completion；不排序修复真实证据。
- 基线cursor后的已声明前置变化可以预热至首个采样；采样以事件边界和已知end再裁剪。Completion分别保留输入窗口、实际采样窗口和data_through，carry-in未知则left_censored；end未知不改成ongoing/恢复或新结束时间。候选描述不能把缺前置状态藏在Grid里。

STATE/有据范围gap仅使对应对象unknown，新A只恢复该对象。无范围gap保留其他已知观察/资源下界，但本版不支持证明gap闭合：完整总体持续null。这是保守新规则的实现，不是实际Session恢复推断。歧义基线的已知子集也不会因一个后续A被擅自升级为完整分母。

## 路径与资源保护

PathSample保存两ASN原位置、path_ref/observation_ref、原观察时间、Peer/映射引用及当前汇总状态引用。path_basis明确baseline或observed_history，不能叫当前路径；撤回后仍可保留有据的历史路径关联。完整原始segments/AS4/属性字节留在输入字典；样本引用不会改写它们。本版遇AS_SET/confed不生成跨该路径的确定有序关系（保留原路径），普通sequence重复ASN保留原位置。

PathSummary汇总唯一path、观察、方向、prefix及同期采样点和各资源独立峰值。路径出现时间与同期中断时点分别保存；每关系最多三份确定排序样本，完整证据仍为原观察引用。这里首先输出固定集合中的候选有序关联，S3须结合WindowClass选择其“受影响AS”展示范围，不能把所有关联都解释为受影响或依赖。

批次受batch_rows及batch_bytes约束；单行过大失败。max_objects限制输入参考、基线/动态对象、路径字典及保留证据集合；max_relations限制关系数；max_changes限制变化行数。guard在迭代/计算/输出期间调用，可接RSS或取消保护。仅保留当前对象索引、固定成员索引、窗口分类/独立峰值/有界路径证据；不缓存全部时点矩阵，消费者可直接写Parquet批次。原对象及路径字典按引用复用，多个国家不各自克隆整份历史。真实规模性能未测，不宣称已达到D吞吐。

正常迭代结束并取得所有Completion才可视为纯计算完成。sink若已写部分批次而发生异常，必须保持候选并丢弃本次完成资格。本轮不实现存储回滚、PG登记、publication、恢复或自动重试。
