### 有限状态的最小补充

1. **顺序与精度**：changes保留有序位置和event_id，但after_epoch仅秒；通过event_id→elements.message_id→messages取microsecond和原MRT引用，不要求重解析。STATE失效由invalidations.source关联message恢复精度；不能只按秒排序。Reader保留源内物理顺序，跨源按绑定source清单，时间回退/相交另标质量，不用时间排序悄悄改变既定计算顺序。
2. **基线与delta**：以明确baseline source及cutoff cursor读取基线elements/paths，按changes推进，合并invalidations；不能读取已经到终点的PG current_routes代替历史。当前invalidations缺独立source_rank/ordinal，应由source message索引推回有序位置；推不回就拒绝该段肯定状态，下一版补直接cursor即可。
3. **确定性适用证据**：没有可证实的连续有效区间/Session关联、RIB/UPDATE切点证明或缺口起止，就没有持续“当下可见”保证。增加国家状态行的 `presence`、`basis`、`validity_state`、`last_observed_at/ref`、`invalidated_at/ref`、`rule_version/limitations`；原资料仍缺的证据记unknown，不补造session_id。last_known永远带原时点。
4. **参考解释**：`references`已留原行、表/行/字节引用、effective_time_state=unknown；仍需国家模块的typed origin→country／静态字段解释与冲突选择规则、历史适用性。不从ip_bgp_entity.csv推断D真实起源；不从当前名称资料推断历史有效。
5. **明确的兼容结果**：若使用现有calculation-replay/v1端点键与假定继承，可生成 `calculation_estimate` 数列，绑定cutover_assumed/source_order_declared/session_continuity_unknown；这不是canonical时点存在性。规范received投影拒收普通LOCAL；旧Feature/Detection双向compatibility projection单列，不拿来填新国家缺项。

### cohort、方向和时间规则

- 建议事件锚点为已知onset之前最后一个可用cursor；onset未知时可显式选detected_at之前，但必须命名 `pre_detection`，不能叫事件前正常基线。用baseline中至少一条明确起源映射到该国家的前缀入集；同前缀保留所有明确起源、unknown起源观察和全部当时选中方向。国家归属有冲突或历史适用性未知另计质量。
- 新方向键为collector内有据Peer identity + AFI/SAFI + prefix；ADD-PATH多个path_id是此方向下的路由对象，不扩分母。没有稳定Peer关联时，只能用明确命名的endpoint/fragment计算方向并标证据限制，不把同IP/ASN自动连成Session。旧Prefix×VP独立键 `(prefix, AF, peer_asn)`，带legacy规则和多Peer折叠映射；两套分母永不互换。
- 每成员基线方向固定。后来的新方向或新前缀进入独立observed_new集合；消失不删分母。空cohort是有状态的空集合，比例null/denominator_zero，不能使用旧schema minimum=1强行造一个成员。
- D结果窗口为UTC `[2026-02-27T16:00:00Z,2026-02-28T16:00:00Z)`。`input_window`、`event_window`、`sample_window`分列；建议5分钟槽采用槽右端左极限 `state(t-)`，只纳入时间<t的输入，D右端用于截至状态标签，绝不包含右端消息。首点为D起点+5分钟，288点仅在完整规则和全日范围成立时由网格算出，不能由288个文件直接认定288个有效状态点。基线另存，不混入序列点数。
- 跨日活动需要沿用原incident/cohort与其前置状态；缺carry-in则标unknown/left_censored，不能用D首RIB替原事件前基线。D末仍无结束证据时end=null、end_state=unknown；仅有明确生命周期活动证据才能加right_censored/active_as_of，截止不是恢复，观测时长不是完整事件时长。

### 三值矩阵与分类规则（已接受的新规则）

每固定方向保存present/absent/unknown及依据。多path_id按有据状态聚合：至少一个present可支持该计算方向存在；没有present且全部所需对象有据absent才为absent，其余unknown。会话失效产生unknown，不制造withdraw。

Prefix在全部预期方向present时正常，全部absent时完全中断；有present且有absent且无unknown时部分中断；其他组合unknown。可另存已知present/absent/unknown计数保留有限事实，不能把unknown计入已确认不可见量。ASN按冻结prefix集合聚合：全正常→normal，全完全中断→route_interrupted，全部可分类且至少一个受损但非全完全→affected，其余unknown。这是保守新规则建议，**不是已查明的历史分类算法**；历史两类互斥与纳入规则仍沿用0A Unknown。

分开存三种结果：`asn_state(asn, sample, AF, state, counts, evidence)`；`asn_window_classification(asn, window, rule, included_reason)`；`metric_peak(metric, value, sample_ref, tie_policy)`。建议窗口分类优先曾route_interrupted、再曾affected、再normal，其余unknown，另存observed/unknown槽数；峰值每指标独立，平峰取最早样本且保留计数。不要把窗口分类投影回所有时点，也不要用各指标独立最大值拼一个不存在的峰值快照。

IPv4地址量是前缀覆盖并集，不是/24段数；IPv6量是地址并集除2^80的/48等价量，细于/48允许分数，建议typed DECIMAL/精确分子分母，不能照旧integer合同截断。未知归属保留在未归属观察集合，不能映射到ASN 0；MOAS关系保留，国家资源去重，逐ASN资源不加总为国家值。

路径保留原始segment类型、顺序、重复ASN、AS_SET/AS4属性和path_key。只有可确定有序位置才生成前后关系，记录两个位置与解释规则；AS_SET不能排成确定顺序。关系并非直接邻接／依赖／原因，参考AS关系标签另外绑定原行和有效性。样本记录source/message/element/path/Peer/原时间、关联样本时点和状态refs；历史last_known样本与当下比较缺项分开。相同路径字典可复用，route_observation_count按观察ID计，不按路径去重；样本按固定排序截取，全部证据保留引用。

### A事实与B有界计算的字段及反例（父任务已明确可计算边界）

A轨道描述有限原始事实／有据的present、absent、unknown；B轨道描述 `calculation_before/after` 加已声明基线映射及继承假设的结果。B直接消费已有changes/invalidations，不再调用规范Replay，不重解析MRT。B不是旧Peer ASN折叠的Prefix×VP：其endpoint键保留collector、remote、local/interface、AFI/SAFI/prefix/path_id，另有独立legacy方向口径。

每一指标分别保存 `fact_value/fact_state/fact_basis_refs` 与 `calculation_value/calculation_state/calculation_rule/assumptions`，共享cohort、输入snapshot/cursor和单位。B绑定 `baseline_mappings`、`projection_metadata`、`rule_version`、LIMITATIONS及完整预期方向集合；A unknown不意味着B必须null。页面可写“按已保存基线与更新重建：X；会话连续性未证实”，同时将“确定观测状态”显示为未知。不能仅放一个笼统quality=complete让用户以为数值是确定事实。

| 前缀AS_SET起源未知，或国家映射冲突；另有明确该国起源 | 未知起源原观察保留；不能强归ASN | 有明确该国起源的prefix按冻结规则入集并保存unknown观察；只有未知起源的prefix留未归属集合，不能计为国家新成员。B仍可统计已知归属子集，历史有效性限制保留 |

无缺口且映射明确时，B固定分母及计数可正常输出，即使A连续性unknown。方向known_present/known_absent/unknown_count可分别返回；完整分母已固定时其合计须等于分母，但分子含未知时exact_ratio为null，可另给显式上下界。资源有unknown候选前缀时保存known_visible_union下界与exact_state，不作地址量加法估计。由此需要新增的是国家聚合器的分项质量／子集状态，不是新Session推断器。

这些建议的最小fixture是“一前缀、两个端点、一个歧义RIB映射或一个STATE失效”，可以人工算出known/unknown计数；先在该例冻结行为，再扩展全体国家。不能用一个事实unknown状态直接抹掉合法B结果，也不能用B数值填A。
