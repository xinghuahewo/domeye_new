# 领域文档

采用 single-context：根目录 `CONTEXT.md` 与 `docs/adr/`。

## 阅读规则

探索领域代码前，读取根目录 `CONTEXT.md`；
涉及具体领域决策时，读取 `docs/adr/` 中相关 ADR。

文件不存在时继续当前工作，不为满足目录结构提前创建。
术语或决策确需新增、修订时，再按授权使用 domain-modeling。

## 使用规则

任务标题、设计讨论、代码和测试中的领域概念沿用 CONTEXT.md 的定义。
遇到尚未定义的概念，先判断是否真的需要新增术语，不随意替换已有名称。

与现有 ADR 冲突时，明确指出冲突及重新讨论的理由，不静默覆盖。
保留文档中的“已确认”“假设”“未实现”“未验证”等状态边界。

本次配置不重写 CONTEXT.md，不新增或修改 ADR。
