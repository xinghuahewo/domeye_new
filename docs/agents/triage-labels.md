# 分诊标签

| 标准角色 | GitHub 标签 | 含义 |
|---|---|---|
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充必要信息 |
| ready-for-agent | ready-for-agent | 规格明确，可由 Agent 执行 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

skill 提及分诊角色时，使用表中对应标签。
标签表示分诊状态，不代表实施、数据准入或验收已经完成。
以后需要调整标签名称时，修改此表的 GitHub 标签列。
