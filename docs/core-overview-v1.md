## 4. 首个数据切片的验收条件

1. **来源可说明。** 明确 Collector／输入对象范围及覆盖限制；数据来自同一个库或同为 `source=r` 不足以证明范围一致。

3. **记录可对账。** 事件身份能唯一定位事实记录；前缀、发生时间、结束信息和等级可核对。不同类型不得把描述文本直接当成 Prefix 或 ASN 身份。
4. **统计可解释。** 同一版本、地址族和时间桶下，柱值等于列表中前缀中断记录的去重 Prefix 数；不暗含旧时长、编号、静态 INFO 成员过滤。确有排除条件时，应显式定义并在图表和列表共同应用。
5. **未知可保留。** 缺表、读取失败、覆盖不明、身份不明与无匹配记录区分；未记录结束时间不参与“持续中”推断。
